# ModuloCarousel

A modular and lightweight carousel library.

## Status

🚧 Work in progress

## Goals

- Modular architecture
- Plugin system
- Fully typed API
- Lightweight and framework-agnostic

## Features (planned)

- Core navigation (next, prev, goTo)
- Event system (beforeChange, change, render)
- Renderer abstraction
- Plugin system (controls, keyboard, etc.)
